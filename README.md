# AfroNative Entertainment - Official Web Platform 🌍✨

A vibrant, culture-driven digital platform for **AfroNative Entertainment** — celebrating African creativity, elite parties, lifestyle experiences, and community.

---

## 🎨 Brand Identity (2026 Edition)
- **Primary Colors**:
  - Deep Black: `#0D0D0D`
  - African Earth Rust: `#B3261E`
  - Ochre Gold: `#E5A719`
  - Heritage Teal: `#146C64`
  - Pure White: `#FFFFFF`
- **Typography**: Syne (Display / Cultural Expression) & Plus Jakarta Sans (Clean Modern Body)
- **Motifs**: Scalable SVG African geometric patterns and CSS animated `stroke-dasharray` typography.

---

## 🚀 Features
- **Hero Section**: High-contrast venue backdrop with dynamic SVG stroke animation.
- **Company Movement & Ethos**: Vision statement, mission statement, and 4 core brand pillars.
- **Past Events & Memories**: Curated gallery of past events, crowd energy, fashion, and culinary grills.
- **Next Upcoming Event**: Dedicated showcase for current flyer editions (synchronized for Python Admin).
- **Official Social Hub**: Accessible direct links and vector badges for Instagram, X (Twitter), TikTok, and Snapchat.

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Ben-agalisi/Afronative_website.git
   cd Afronative_website
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local server:
   ```bash
   npm start
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
